# Cinema Home

A tiny, fast Android TV home screen for the Wanbo Vali 1: a big hero area for the focused app, one row of app cards, a clock and a settings button. No libraries, no ads, no recommendations.

Pushing to this repo builds `app-release.apk` with GitHub Actions (see the Actions tab → latest run → Artifacts).

Change which apps come first in `FAVORITES` in `app/src/main/java/sk/peto/cinema/MainActivity.java`.
